📥บันทึกน้ำหนักรับเข้าเมล็ดพันธุ์

กรอกข้อมูลแยกตามรหัสเกษตรกร — บันทึกแล้วจะซิงก์ขึ้นคลาวด์ทันที
Optional — ใส่หรือไม่ใส่ก็ได้
วันที่ชนิดพืชสายพันธุ์รหัสเกษตรกรน้ำหนัก (กก.)ชื้น %แข็งแรง %งอก %บริสุทธิ์ %1,000 เมล็ดข้อเสนอแนะสถานะ

👨‍🌾รายชื่อเกษตรกร

โปรไฟล์เกษตรกร ข้อมูลติดต่อ และประวัติส่งมอบเมล็ดพันธุ์ทุกฤดูกาล — เกษตรกรจะถูกเพิ่มอัตโนมัติเมื่อบันทึกรับเข้า
👨‍🌾
ยังไม่มีรายชื่อเกษตรกร — กด "＋ เพิ่มเกษตรกร" หรือบันทึกรับเข้า ระบบจะเพิ่มให้อัตโนมัติ

📊 รายงาน: เกษตรกรแต่ละคนส่งออกไปประเทศไหนบ้าง

รหัสเกษตรกรประเทศปลายทาง (น้ำหนักส่งออก)รวมส่งออก (กก.)

🔀เลือกเกษตรกรเพื่อรวมล็อต

🔗 แชร์ห้องทำงานนี้

ส่งลิงก์นี้ให้เพื่อนร่วมทีม — ทุกคนจะเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ (ดู + กรอกได้)
⚠️ ลิงก์นี้ยังเปิดได้เฉพาะเครื่องนี้ เพราะแอปยังรันจากไฟล์ในเครื่อง — วิธีให้เปิดได้ทุกอุปกรณ์: อัปโหลดไฟล์ index.html ขึ้นโฮสติ้งฟรี เช่น netlify.com/drop (ลากไฟล์วาง ได้ลิงก์ https ทันที) หรือ GitHub Pages แล้วนำลิงก์ https ที่ได้ + ?room=main ส่งให้ทีม — ข้อมูลจะซิงก์กันอัตโนมัติเพราะเก็บบนคลาวด์อยู่แล้ว
เมื่อใส่ URL แล้ว ข้อมูลจะถูกเซฟซ้ำไปยัง Firebase แบบเรียลไทม์ด้วย (ใช้ textdb.dev ไปพร้อมกันได้) — เว้นว่าง = ใช้คลาวด์ปกติ
